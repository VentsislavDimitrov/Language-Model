Language Model | Python, PyTorch, OpenAI’s Byte-Pair Encoding Tokenizer	
Developed a Language Model, using PyTorch to build the systematic components, including OpenAI’s Byte-Pair Encoding Tokenizer to convert text input into tokens and utilizing OpenAI’s pre-trained GPT-2 weights initialization baseline.
The project is designed to demonstrate how the internal components work together beyond API interference.
Assembled systematic components that include 12 layers of Transformer Block to learn how different parts of inputted text are related to each other and GPT Model’s Neural Network, responsible for converting the tokenized input to logits, used for prediction.
Implemented the training algorithm and fine-tuned it for classification.
Achieved 61.50% accuracy during instructions training and 73.2% accuracy during classification training, leading to foundational understanding of how the GPT Models operate and demonstration of model’s ability to conclude beyond memorization.

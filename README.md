Language Model | Python, PyTorch, OpenAI’s Byte-Pair Encoding Tokenizer	
Developed a Language Model, using PyTorch to build the systematic components, including OpenAI’s Byte-Pair Encoding Tokenizer to convert text input into tokens and utilizing OpenAI’s pre-trained GPT-2 weights initialization baseline.
The purpose of this project is to build practical understanding of what really is happening in the background, when interacting with text completion AI.

Implemented systematic components that include 12 layers of Transformer Block to learn how different parts of inputted text are related to each other and GPT Model’s Neural Network, responsible for converting the tokenized input to logits, used for prediction.
Implemented the training algorithm and fine-tuned it for classification.

Achieved 61.50% for Training Accuracy and Validation Accuracy during classification.
Currently fine-tuning the Language Model for instruction following to expand the text completion capabilities.
